# ナビアン計算バトル

TT-sensei の計算バトル教材。GitHub Pages で動く静的 HTML / CSS / JavaScript プロジェクトです。

## 開発方針
- API・外部サービス・バックエンド・データベースなし
- ビルド工程なし。ES Modules をブラウザで直接実行
- 学習データは localStorage に保存
- タブレット優先の大きなタップ領域
- 人間のナビキャラと、モンスターのナビアンが対戦
- このリポジトリ内で独立して開発

## 構成
- index.html : 画面構造
- css/style.css : デザイン・レスポンシブ対応
- js/data/units.js : 単元カタログ
- js/engine/question-generator.js : 問題生成
- js/game/battle.js : CPUバトルの状態管理
- js/app.js : 画面と各機能の接続

## 単元・問題の拡張
単元の学年・難易度・出題範囲は units.js の OPERATIONS に定義します。問題生成処理は question-generator.js にまとめ、設定を読み取って条件に合う問題を作ります。単元定義と生成ロジックを分離しているため、新しい単元を追加しやすい構造です。

たし算・ひき算の「くり上がり／くり下がりなし」は、1の位だけでなく、すべての位を調べて条件を判定します。わり算は、設定した桁数のわる数・わられる数になるように商の範囲を計算してから問題を作ります。

## バトル
- バトル設定: 出題数（5・10・15・20問）と難易度（やさしい・ふつう・つよい）をホーム画面で選択でき、設定は localStorage に保存される。難易度は敵の攻撃間隔とダメージだけを変え、問題の内容・数は変えない
- ナビキャラ特性: ソラ=受けるダメージ軽減、カイ=必殺技ゲージがたまりやすい、サク=正解でHP回復、ツキ=敵の攻撃間隔が長くなる、ナミ=攻撃ダメージアップ、リク=バランス型（特性なし）
- 敵ナビアンは単元レベルで出し分ける（レベル1〜2: HP100、3〜4: HP120、5: HP150）
- プレイヤーのレベル制: XPがたまるとレベルアップ（最大レベル20）。レベルが上がると最大HPが+10ずつ増える（レベル20でHP290）。攻撃力は上げないので、1バトルの演習量は変わらない
- 教材表記の改善: 分数の問題文は約分済みの数で出題し、「約分すると」の説明は実際に約分するときだけ表示する。小数の解説は答えと同じ表記（末尾の0なし）に統一。保存データが壊れていた場合は初期化して起動する
- 間違いの型の記録: 間違えた答えのパターンから型（くり上がり・くり下がり／けたのずれ／ちがう計算／数字の入れかえ／約分していない／分数のしかた／商とあまり／そのほか）を推定して記録する。結果画面と特訓で型を表示し、ホームの記録欄に型ごとの件数・特訓で克服した問題数・単元ごとの得意／苦手を表示する
- 経験値の周回防止: 自分のレベル帯（レベルを4で割った段階）より1つ易しい単元は経験値が半分、2つ以上易しい単元は経験値が入らない。単元カードと結果画面で理由を表示する
- スピードボーナス: 速く解くほど追加ダメージ（目安時間は単元レベル連動、+10/+6/+3の段階式。遅くてもペナルティはない）
- 問題を解く時間は無制限。正解するまで同じ問題に挑戦
- ナビアンの攻撃は独立した周期タイマーで、単元レベルに応じて20・26・32・39・46秒
- 攻撃予告バーを表示し、正解すると次の攻撃カウントをリセット
- 不正解・ナビアンからの攻撃では問題を切り替えない
- 正解10問を目標にしたCPUバトル、HP、コンボ、必殺技、勝敗
- XP、勝利数、バトル・特訓の成績、間違えた問題を localStorage に保存
- 間違えた問題は回答時点で保存するため、バトルを途中でやめても記録が残る
- 特訓モードは10問。敵・HP・制限時間なしで、苦手な単元から新しい問題を出題
- 特訓で同じ単元を3問正解すると、その単元の苦手記録を克服済みにする。不正解で連続正解数をリセット
- 単元カードに挑戦回数・正答率・クリア状況を表示し、トップ画面に全体の学習記録を表示

## おすすめ・あまり・演出
- 単元のはしごでまだクリアしていない最初の単元に「⭐ つぎはこれ！」を表示。勝利後の結果画面には「つぎの単元へ」ボタンが出る
- あまりのあるわり算を公開（商とあまりの2欄入力。欄をタップして切り替え、両方そろうと判定）
- バトルの演出: ダメージ数字のポップ表示、撃破時の倒れ演出、Web Audioによる効果音（ヘッダーのボタンでON/OFF、設定は保存される。音源ファイルは使わない）
- スピードボーナス: 速く解くほどダメージが大きくなる（目安時間は単元レベルで変わる。遅くてもペナルティはない）
- 解説の活用: 同じ問題で2回間違えると解説がヒントとして出る。特訓で間違えたときと、結果画面の間違い一覧でも解説を表示する
- 特訓は「記録した間違えた問題そのもの」から出題し、正解するとその問題の記録が消える（克服）。足りない分は単元の新しい問題で補う
- 単元は全部で68（たし算15・ひき算15・かけ算10・わり算9・分数8・応用11）。各タブの並び順がそのまま「おすすめ（はしご）」の順番になる
- 分数と比の答えは2欄入力（ぶんし／ぶんぼ、ひだり／みぎ）。分数の答えは約分した仮分数で答える
- バトル開始時にVS画面（自キャラと敵の対決表示）を出し、結果画面にも両者のイラストを表示する
- キャラの絵は場面で切り替わる: 正解で攻撃ポーズ、必殺技で必殺技ポーズ、敵の攻撃を受けるとダメージポーズ（ナビキャラサイトの fantasy/attack・damage・special 素材）
- トップ画面にもファンタジー背景とモンスターのイラストを配置している
- ファンタジーの集合絵も場面ごとに使う: VS画面の背景（アクション集合絵からランダム）、結果画面のバナー（勝利=クリア／報酬の絵、敗北と特訓終了=休憩の絵）、図鑑画面のバナー（待機の絵）、トップ画面下部のバナー（エンディングの絵）
- ふりがな: ヘッダーのボタンでON/OFF（設定は端末に保存、既定はON）。js/furigana.js の辞書にある「読みが固定できる言葉」にだけルビを振り、後から表示される文章にも自動で付く。文脈で読みが変わる漢字（分・上・下など）は辞書に入れていない

## 画像と図鑑
- キャラ・敵・背景の画像は、ナビキャラサイト（navi-character-）の公開素材（ファンタジーのキャラ立ち絵・背景・モンスター画像）を参照する。アプリ本体に画像は含めない
- 敵ナビアンは単元レベルでプールが変わる（レベル1〜2: 通常、3: 通常＋進化、4: 進化、5: 進化＋ボス）。背景はバトルごとにファンタジー背景10種からランダム
- 勝利すると敵がナビアン図鑑に登録され、倒した回数が記録される（localStorage の dex）。未登録はシルエットと「？？？」で表示

## 学習記録・特訓
- 単元ごとのバトル記録、正答率、クリア状況を表示
- 苦手を特訓するボタンから、間違えた単元を横断して10問練習
- 特訓は問題ごとの制限時間なし。正解するまで同じ問題に取り組める
- 3回正解で単元の苦手記録を克服済みにし、記録から除外
- 成績は端末内の localStorage に保存。別端末への同期は行わない

## 現在の単元
- たし算：20まで、□の数をもとめる逆算、2けた＋1けた、2けた＋2けた、3けた＋2けた、3けた＋3けた、4けた＋3けた、4けた＋4けた（くり上がりの有無を選べる単元あり）
- ひき算：20まで、□の数をもとめる逆算、2けた−1けた、2けた−2けた、3けた−2けた、3けた−3けた、4けた−3けた、4けた−4けた（くり下がりの有無を選べる単元あり）
- かけ算：九九、□の数をもとめる逆算、2けた×1けた、2けた×2けた、3けた×1けた、3けた×2けた、4けた×1けた、4けた×2けた
- わり算：九九を使うわり算、□の数をもとめる逆算、2けた÷1けた、3けた÷1けた、4けた÷1けた、4けた÷2けた（わり切れる計算）、小数÷整数、小数÷小数
- 小数：小数第1位・第2位のたし算／ひき算、小数×整数、小数×小数、小数÷整数、小数÷小数（わり切れる問題）
- 応用：3つの数の合計・平均、最小公倍数、最大公約数、くらべる数・もとにする量・割合、速さの基本

公開前に、各単元の生成範囲・計算結果・境界値、連続操作・中断時のタイマー処理、タブレット実機での確認を行ってください。
