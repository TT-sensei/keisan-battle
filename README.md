# ナビアン計算バトル

TT-sensei の計算バトル教材。GitHub Pages で動く静的 HTML / CSS / JavaScript プロジェクトです。

## 開発方針
- API・外部サービス・バックエンド・データベースなし
- ビルド工程なし。ES Modules をブラウザで直接実行
- 学習データは localStorage に保存
- タブレット優先の大きなタップ領域
- 人間のナビキャラと、モンスターのナビアンが対戦
- このリポジトリ内で独立して開発

## 構成
- index.html : 画面構造
- css/style.css : デザイン・レスポンシブ対応
- js/data/units.js : 単元カタログ
- js/engine/question-generator.js : 問題生成
- js/game/battle.js : CPUバトルの状態管理
- js/app.js : 画面と各機能の接続

## 拡張方法
単元追加は units.js の OPERATIONS に定義を追加。既存の問題生成器で対応できない形式は question-generator.js に生成関数を追加し、generator 名で接続する。単元定義と生成ロジックを分離しているため、小数・分数・計算の工夫などを後から追加できます。

バトルの HP・CPU 回答速度・コンボ・攻撃力・必殺技は battle.js に集約。画面表示は app.js が担当します。

## 初期プロトタイプ
- 整数のたし算・ひき算・かけ算・わり算
- くり上がり・くり下がり、九九などの単元カタログ
- CPU 戦、正解10問を目標にしたバトル、HP、コンボ、必殺技、勝敗
- 問題回答と敵の攻撃周期を分離。問題の回答時間は無制限
- 敵の攻撃周期は単元レベルに応じて18〜30秒。攻撃予告バーを表示
- 正解時に敵へ攻撃し、敵の次回攻撃カウントをリセット。不正解・被弾では問題を切り替えない
- XP、勝利数、間違えた問題の保存
- 小数の単元は先行登録、問題生成は今後実装
- あまりのあるわり算は商とあまりの複数入力UIが未実装のため準備中

公開前に問題生成の境界値テスト、連続操作・中断時のタイマー処理、タブレット実機での確認を行ってください。
